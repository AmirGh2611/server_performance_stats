# server_performance_stats
Write a script to analyse basic server performance stats.

# project URL
<https://roadmap.sh/projects/server-stats>

# usage
### 1-first make the file using command below
> touch server-stats.sh
### 2-open the file
> vi server-stats.sh
### 3-edit the file
> press i and paste the code in file
### 4-save the file
> go to the end of the file and write :wq in a new line
### 5-make file executable
> write chmod +x server-stats.sh
### 6-run the file
> ./server-stats.sh
